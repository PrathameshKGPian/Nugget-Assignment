# Restaurant RAG Chatbot

This repository provides a workflow for building a Retrieval-Augmented Generation (RAG) chatbot focused on restaurant data from Zomato (Agra). The project is designed to be run on **Kaggle Notebooks** for seamless package support and access to Hugging Face models.

---

## Workflow

### 1. Scrape Restaurant Data

Run `web_scraper.py` to collect restaurant details from Zomato and save them to `restaurants_data.json`:

This will generate a `restaurants_data.json` file in your working directory.

However, a sample `restaurants_data.json` file is already provided which alsready contains scraped restaurant details.

### 2. Run the RAG Chatbot

After generating the JSON data, run the chatbot script:


- The chatbot loads `restaurants_data.json`, embeds the data, and enables you to ask questions about the restaurants.
- **Example question:**  
  _"Which restaurant has the lowest price for two?"_

---

## File Descriptions

| File                   | Description                                                                 |
|------------------------|-----------------------------------------------------------------------------|
| `web_scraper.py`       | Scrapes restaurant data from Zomato and saves it as `restaurants_data.json` |
| `restaurants_data.json`| JSON file containing structured restaurant data (generated by scraper)       |
| `rag_chatbot.py`       | Loads the data and runs the RAG chatbot for Q&A                             |

---

## Usage Notes

- **Kaggle Secrets:**  
  Store your Hugging Face API token in Kaggle Secrets as `hf_token` for authentication.
- **Running Order:**  
  1. Run `web_scraper.py` to generate the data.
  2. Run `rag_chatbot.py` to interact with the chatbot.
- **Customization:**  
  You can modify the scraper to target different cities or data fields as needed.
